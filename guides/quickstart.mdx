<Steps>
  <Step title="Create an account">
    Go to [app.linkvite.io](https://app.linkvite.io) and sign up. The free plan has no time limit; see [plans](/guides/plans) for what it includes.
  </Step>
  <Step title="Save your first link">
    Press <kbd>C</kbd> (or select **Add**) and paste a link. Linkvite fetches the page's title, description and preview image for you. You can also add a note, upload a file or create a collection from the same dialog.
  </Step>
  <Step title="Organize it">
    Bookmarks without a collection land in **Unsorted**. Move them into [collections](/guides/collections), add tags, or star the ones you come back to often.
  </Step>
  <Step title="Get the apps">
    Install the apps for the devices you use. Everything you save syncs across them.

    | Platform | Where |
    | --- | --- |
    | Web | [app.linkvite.io](https://app.linkvite.io), in any browser |
    | iOS | [App Store](https://apps.apple.com/app/linkvite) |
    | Android | [Google Play](https://play.google.com/store/apps/details?id=io.linkvite) |
    | Browser extension | Chrome, from the [download page](https://linkvite.io/download) |
  </Step>
</Steps>
