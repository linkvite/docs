Press <kbd>?</kbd> in the web app to see this list at any time. <kbd>⌘</kbd> is <kbd>Ctrl</kbd> on Windows and Linux.

## General

| Shortcut | Action |
| --- | --- |
| <kbd>⌘</kbd> <kbd>K</kbd> | Search |
| <kbd>C</kbd> | Add a link, file, collection… |
| <kbd>⌘</kbd> <kbd>\\</kbd> | Toggle sidebar |
| <kbd>?</kbd> | Keyboard shortcuts |

## Go to

Press <kbd>G</kbd>, then the second key.

| Shortcut | Page |
| --- | --- |
| <kbd>G</kbd> <kbd>A</kbd> | All bookmarks |
| <kbd>G</kbd> <kbd>D</kbd> | Discover |
| <kbd>G</kbd> <kbd>S</kbd> | Settings |
| <kbd>G</kbd> <kbd>I</kbd> | Invites |
| <kbd>G</kbd> <kbd>R</kbd> | Reminders |
| <kbd>G</kbd> <kbd>N</kbd> | Notifications |
| <kbd>G</kbd> <kbd>U</kbd> | Unsorted |

## Selection

| Shortcut | Action |
| --- | --- |
| <kbd>⌘</kbd> <kbd>A</kbd> | Select all |
| <kbd>Shift</kbd> + click | Select a range |
| <kbd>Esc</kbd> | Clear selection |

## Reader

| Shortcut | Action |
| --- | --- |
| <kbd>⌘</kbd> <kbd>F</kbd> | Find in page |
| <kbd>Enter</kbd> | Next match |
