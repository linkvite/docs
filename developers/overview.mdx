The Linkvite API is a JSON REST API. It covers everything the Linkvite apps do: bookmarks, notes and files, collections and sharing, highlights, reminders, RSS feeds, profiles and search.

| | |
| --- | --- |
| Base URL | `https://api.linkvite.io` |
| Staging | `https://api-stg.linkvite.io` |
| Format | JSON requests and responses; file uploads use `multipart/form-data` |
| Authentication | An [API key](/developers/api-keys) or an [OAuth](/developers/oauth) access token |
| Specification | OpenAPI 3.1, the source of the [API reference](/api-reference) and the SDKs |

The specification is generated from the API's own code, so the reference and the SDKs always match what the server does.
